# ImageCast

Search for an image and put it fullscreen on a second screen (a TV or projector on HDMI).

**Open it:** https://colabourers58-hue.github.io/imagecast/

## How to use it
1. Plug in the HDMI screen and set it to *extend* your desktop (not mirror).
2. Open ImageCast in Chrome or Edge and click **Open display**. Allow window placement if asked. The display window opens on the other screen. Click it once to go fullscreen.
3. Search. Click any picture to put it on the big screen. Arrow keys step through results, **B** blacks out the screen.

If your screens are mirrored, use **Fullscreen on this screen** instead.

## Sources
- Work straight away: Openverse (Flickr and museum collections), Wikimedia Commons, NASA.
- Need a free key (click **Sources**): Unsplash, Pexels, Pixabay.
- Google: the **Google Images ↗** button opens your search on Google. Drag any picture back into ImageCast, or copy it and paste with Cmd/Ctrl+V.

You can also drop in image files from your computer or paste an image link into the search box.
